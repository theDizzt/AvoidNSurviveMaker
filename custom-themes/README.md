# 커스텀 테마 프리셋

공식 캠페인과 별도로, 커스텀 용도로 보존해 둔 원래 테마 팩들입니다.

- `01-pastel-plains` — Pastel Plains
- `02-whisper-woods` — Whisper Woods
- `03-sugar-switchworks` — Sugar Switchworks
- `04-neon-circuit` — Neon Circuit
- `05-ember-core` — Ember Core
- `06-monochrome-void` — Monochrome Void

**Theme Editor → Start from → Custom theme presets** 에서 테마를 고른 뒤 **Play as custom pack** 또는 **Export .zip** 을 사용하세요. 초안을 편집해도 이 번들 파일은 바뀌지 않습니다. 원래의 맵, 표지 아트, 테마 설정이 포함되어 있습니다.

`_template/` 은 빈 시작점이며 프리셋 목록에는 나오지 않습니다. 재사용할 팩을 추가하려면 `theme.json`, 선택적 에셋, `levels/*.json` 이 들어 있는 폴더를 여기에 만들면 에디터에 자동으로 포함됩니다. 공식 캠페인에는 `themes/` 에 등록된 팩만 나타납니다.

필드 정의는 [테마 형식](../themes/README.md) 을 참고하세요.
