# Custom theme presets

These original theme packs are preserved for custom use, outside the official campaign:

- `01-pastel-plains` — Pastel Plains
- `02-whisper-woods` — Whisper Woods
- `03-sugar-switchworks` — Sugar Switchworks
- `04-neon-circuit` — Neon Circuit
- `05-ember-core` — Ember Core
- `06-monochrome-void` — Monochrome Void

Open **Theme Editor → Start from → Custom theme presets**, select a theme, then use
**Play as custom pack** or **Export .zip**. Editing a draft does not modify these bundled files.
The original maps, cover art and theme settings are included.

`_template/` is a blank starting point and is not listed as a preset. Add new reusable packs
as folders here with `theme.json`, optional assets, and `levels/*.json`; they are automatically
included in the editor. Only registered packs in `themes/` appear in the official campaign.

See [the theme format](../themes/README.md) for field definitions.
