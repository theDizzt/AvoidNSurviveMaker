# 전체 어둠과 광원

42번 전체 어둠을 켜면 레벨 설정에서 어둠 강도(0–100%)를 조절할 수 있다. 0은 어둠을 그리지 않고, 100은 광원이 비추지 않는 맵을 완전히 검게 가린다. 게임 UI와 결과 화면은 기존처럼 읽을 수 있다. 41번 어둠 영역과 안개는 별개 효과다.

새 설정의 기본값은 `{ "light": 60, "intensity": 100 }`이다. `light`는 커서 빛 반경이며 0으로 설정하면 자동 빛을 끈다. 기존 맵에서 강도가 생략된 경우 100으로 해석하고 기존 커서 빛 반경은 유지한다. 시작 전 커서 빛도 반경이 0일 때 생성하지 않는다.

에디터에서는 선택과 편집을 위해 실제 강도의 30%로 어둠을 미리 표시한다. 실제 강도는 테스트 플레이에 반영된다.

## 향후 광원 오브젝트 연결

광원 전용 팔레트는 아직 추가하지 않았다. 기존 `MapObject`에 아래 속성을 부여하면 이미 렌더링에 반영된다.

```json
"light": { "radius": 160, "intensity": 100 }
```

- `radius`: 맵 좌표 기준 반경, 0이면 비활성화. 최대값은 `LIMITS.maxLight`.
- `intensity`: 0–100, 생략 시 100. 100이면 중심 영역의 어둠을 완전히 제거하고 가장자리에서 부드럽게 줄어든다.
- `objectLights()`가 오브젝트의 변환된 중심을 구한다. 이동·회전·개별 시간 정지와 `hidden` 상태를 반영한다.
- 숨겨지거나 제거된 광원은 빛을 내지 않는다. 다시 표시되면 해당 프레임부터 어둠을 걷어낸다.
- 여러 광원은 같은 어둠 마스크를 깎는다. 다른 광원의 밝은 영역을 다시 어둡게 덮지 않는다.
- 현재 빛은 원형 범위이며 벽에 의한 차폐·그림자는 계산하지 않는다. 41번 영역·안개를 제거하는 기능은 포함하지 않는다.
- 검증기가 광원 속성을 보존하므로 저장·공유·불러오기에 포함되고, 게임플레이 변경 시 에디터의 클리어 검증도 무효화된다.

사용자 요청에 따라 플레이 및 자동 테스트는 실행하지 않고 타입 검사만 수행했다.
